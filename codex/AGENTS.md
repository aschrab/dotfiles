If requests are unclear or seem to be misguided ask for clarification before 
proceeding.

When committing to git, include a summary of what changes were made to the code, 
not just a one-line subject. Wrap paragraphs so that lines are no more than 76 
characters long, unless that cannot be done. When implementing a plan that 
involves several phases or steps, each of those should be done as its own 
commit. Pushes to remotes should only be done over ssh; if that fails it's 
likely because the local computer is locked, wait for confirmation before 
retrying.
